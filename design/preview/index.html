My Bodybuilding Program

Approved design (HTML source). Each page shows light and dark. Screen specs: design/README.md. Tokens: design/tokens.json.

Open the clickable prototype

Foundations & components

  1. Foundations: colours, contrast, type, spacing, radius
  2. Components 1: bottom nav, buttons, session card / row, exercise rows
  3. Components 2: set rows, steppers, unit selector, rest + timed-set timers, PR chip
  4. Components 3: multi-unit chart, calendar, streak + week strip, stat tiles
  5. Components 4: dialogs, snackbar, trophy overlay, banner, empty states, picker sheet, chips, unit editor, settings tiles

Screens

  1. Today: normal, after the workout, in progress, empty program, pick another session
  2. Workout 1: session preview, player (reps, resting, timed)
  3. Workout 2: list view, swap, PR trophy, paused, summary + update prompt
  4. Program: program, session editor, catalogue, exercise detail, exercise edit
  5. Progress: calendar, exercises, history, exercise progress, workout detail
  6. Profile: profile, bodyweight, settings, load units, muscles, cloud backup (v1.1)

Prototype flows

  1. Main: Today → Preview → Player (log set → trophy → rest → list → swap) → Finish → Update program → Summary → Today (next session advanced)
  2. Progress → Exercises → Exercise progress
  3. Profile → Settings → Load units

Tools
